02Connected by default

Stop re-typing the same data into five systems

Most companies run HR in one tool, safety in a spreadsheet, purchasing in email and finance somewhere else. Caspian ERP keeps one record of each person, vendor, item and asset, and lets every module read it.

  • One person, every module. Training certificates gate the permits someone can sign, the journeys they can lead and the work orders assigned to them.
  • One item, one number. A procurement item, a stock line, a BOM component and an invoice line all point at the same catalogue record.
  • Reporting that already adds up. Dashboards read live records rather than exports, so the KPI on screen is the number your controller sees.

Multi-tenant, permission-first

Yours to shape, and enforced where it counts

Caspian ERP was built as a tenant-per-organization platform from the first line of code — not retrofitted. Your data lives under your organization, and every read and write is checked against the permissions you granted.

How security works

  • One account, many organizations. Consultants, groups and joint ventures switch between organizations from the same login — data never crosses the boundary.
  • Roles you define. Start from Owner, Admin, Manager and Member, then build roles from read / create / update / delete permissions per tool.
  • Audit log. Membership, role and permission changes are recorded and attributed, so you can answer “who changed this, and when?”.
  • Five languages. English, French, German, Norwegian and Turkish ship with the product — each member picks their own.

08FAQ

Questions people ask before they start

Short answers here; the pricing page has the commercial ones.

More questions on the pricing page

Do we have to adopt all eleven modules?
No. Every department and every individual tool can be switched on or off in Settings. Most teams start with one or two — usually HSEQ or Efficiency — and turn on the rest as they go. The sidebar, search and permissions all follow the switches.
How long does it take to get running?
Creating your organization and inviting your first colleagues takes a few minutes. A realistic first module — people loaded, roles defined, and a workflow live — is usually days rather than months, because there is nothing to install and nothing to host.
Can we bring existing data in?
Yes. The main lists support CSV import and export, so personnel, items, vendors and assets can be loaded from your current spreadsheets or exports. For large or unusual migrations, talk to us before you start.
Who can see what?
Access is permission-based. Each tool has its own read / create / update / delete permissions, roles are collections of those permissions, and every member holds exactly one role in each organization. The rules are enforced server-side, so a permission you did not grant cannot be reached by any client.
Does it work on phones and tablets in the field?
Caspian ERP runs in the browser on desktop, tablet and phone — there is no app to install or update. Field capture such as observations, checklists and attendance is built for small screens.
What happens to our data if we leave?
It stays yours. Lists export to CSV at any time, and we will provide a full export of your organization's records on request before an account is closed.
